# GO Lens — Poke Genie 설명 반영판

사용자가 제공한 IV 설명 4장과 레이드 랭크 설명 2장의 공개 원리를 반영했습니다. Poke Genie의 코드·이미지·디자인은 복제하지 않았으며 참고 스크린샷은 배포물에 넣지 않습니다.

## 반영한 기능

- PvP 대표 점수를 **랭크 백분위수**로 변경하고 스탯곱 비율을 따로 표시합니다.
- 현재 종과 DB에 연결된 모든 진화 분기를 비교합니다. 그림자는 그림자/정화 후보를 함께 평가합니다. 정화 IV는 각 +2, 최대 15이며 정화 최소 레벨 25와 현재 레벨 이하로 낮출 수 없는 조건을 적용합니다.
- 슈퍼/하이퍼 둘 다 설정 백분위수 이상이면 두 리그, 아니면 가장 우선하는 한 리그를 미리보기에 표시합니다.
- 최대 CP가 리그 상한의 설정 비율 미만인 후보를 뒤로 정렬합니다. 기본 90%는 사이트 자체 기준입니다. 첨부 설명에 원 앱의 정확한 경계값은 없습니다.
- PvP 사용 후보 지정, 후보 기반 이름 메모 복사, 진화·정화 후보 표, 4,096개 IV 순위표(100개씩 펼치기)를 추가했습니다.
- 기존 종간 현재 DPS 대표 등급을 없애고, **동일 종·폼 내 기술 조합의 중립 평균 DPS 등급**으로 바꿨습니다. S/A/B/C/D/E/F만 사용하며 S가 최고입니다.
- 현재 개체의 전투 DPS와 레벨 50·IV 100% 기준 배틀 스탯 막대를 분리합니다.
- 영상 프레임 카드, 좌표 보정, 수동 교정, 백업은 유지합니다. 예전 카드는 열면 새 기준으로 재계산하고 재저장 후 카드 미리보기도 갱신됩니다.

## PvP 계산

같은 종·폼의 IV 0–15 모든 4,096개 조합을 비교합니다. 사용자 설정 없이 레벨 50 이하에서 0.5 단위로 CP 제한에 맞는 최적 레벨을 찾고 실제 공격 × 실제 방어 × 정수 HP를 정렬합니다. 동점은 같은 경쟁 순위입니다.

- IV% = IV 합 / 45 × 100.
- **랭크 백분위수 = (4096 − 순위) / 4095 × 100.**
- 스탯곱 비율 = 내 최적 스탯곱 / 같은 종·폼 최상위 스탯곱 × 100.

현재 종의 리그 표는 육성 잠재력을 보여주고, 진화 후보 표는 현재 레벨과 정화 최소 레벨까지 고려합니다. 메가·원시회귀는 PvP에서 제외합니다. 마스터는 일반 IV가 높은 개체가 유리합니다. 종간 메타 순위/승률이 아닙니다.

실제 공격/방어는 (기본 능력치 + IV) × CPM, HP는 max(10,floor((기본 HP + IV) × CPM))입니다. CP는 max(10,floor((기본 공격 + 공격 IV) × sqrt(기본 방어 + 방어 IV) × sqrt(기본 HP + HP IV) × CPM² / 10))입니다. 반 레벨 CPM은 인접 정수 레벨 CPM 제곱 평균의 제곱근입니다. 데이터 정밀도/버전이 다르면 CP 경계와 순위가 다를 수 있습니다.

## 레이드의 재현 범위

첨부 설명은 레벨 40–50 공격자가 다수 보스와 전투하고, 약점·저항을 제외한 평균 DPS로 기술 조합을 평가한다고 설명합니다. **보스 표본·전투 AI·시간/에너지 규칙·등급 경계가 제공되지 않아 Poke Genie의 동일 점수나 등급을 보장할 수 없습니다.** 화면에도 차이를 표시합니다.

| 항목 | 사이트 벤치마크 |
| --- | --- |
| 기술 등급 | 같은 종·폼, 완벽 IV, 일반 상태 |
| 공격자 레벨 | 40, 45, 50 |
| 가상 보스 공격/방어/기술 위력 | 180/150/35, 220/200/45, 260/250/55 |
| 전투 | 180초, 보스 2초마다 공격, 사망 후 10초 복귀 |
| 에너지 | 최대 100, 피격 시 floor(피해/2), 충전되면 스페셜 |
| 피해 시점 | 기술 종료 시점; 그 전에 쓰러지면 공격 무효 |
| 타입 | 약점/저항 제외, 자속 1.2 포함 |
| 기술 점수 | 9개 전투 평균 DPS / 같은 종·폼 최상위 기술 평균 DPS × 100 |
| 등급 | S≥95, A≥85, B≥75, C≥65, D≥50, E≥35, F<35% |

등급 경계는 사용자 요청의 S 최상위를 적용한 사이트 기준입니다. 기술 등급은 현재 IV/레벨과 무관합니다. 현재 개체의 중립 전투 DPS는 현재 레벨·IV·그림자 공격 1.2/피격 피해 1.2를 적용해 별도로 계산합니다. 메가는 해당 폼 능력치를 쓰며 그림자와 동시 적용을 막습니다.

날씨·프렌드·회피·대미지 윈도우·특수 효과·파티·아군 메가 보너스는 미반영입니다. 화풀이/은혜갚기는 최적 기술 비교에서 제외합니다. 출시 그림자 여부·한정 기술 해금·참가 제한은 별도 확인해야 합니다. 실전 특정 보스의 상성별 카운터 순위와 다릅니다.

## 배틀 스탯

첨부 설명의 데미지량 = 공격 × 기술 DPS, 탱커력 = HP × 방어, 배틀 능력치 = 데미지량 × 탱커력 구조를 반영했습니다. 항상 레벨 50·15/15/15 기준이며 현재 개체 값과 구분합니다.

원 앱의 기술 DPS 데이터가 없어 사이트의 중립 위력/초 근사식을 사용합니다. n=ceil(스페셜 소모 에너지 / 노말 획득 에너지)일 때 (n × 노말 위력 × STAB + 스페셜 위력 × STAB)/(n × 노말 시간 + 스페셜 시간)입니다. 그림자는 데미지량 ×1.2, 탱커력 ÷1.2입니다. 각 막대는 DB 전체 일반/그림자/메가의 레벨 50·완벽 IV 최상위 대비 비율이며 출시/특수 효과 미검증 데이터가 포함될 수 있습니다. 원 앱의 동일 막대 값이 아닙니다.

## 사용과 실행

1. 아이폰에서 조사 막대가 보이는 화면을 1–2초 유지하며 녹화한 파일을 선택합니다.
2. 후보 카드에서 전체 막대 시작/끝과 공격·방어·HP 중앙을 차례로 지정해 좌표를 보정합니다.
3. 트레이너 레벨을 입력하고 종·폼, IV 슬라이더와 실제 기술을 확인합니다. CP를 화면에서 자동 판독해 개체 레벨을 추정하며 실패 시 CP 영역을 지정하거나 CP/최대 HP를 교정합니다. 이름/기술 OCR은 미구현입니다.
4. 추천 PvP 후보를 지정하고 기술 조합별 등급과 배틀 스탯을 확인합니다.
5. 누락은 영상 미리보기에서 직접 저장하거나 스크린샷으로 추가합니다. 중요한 기록은 JSON 백업으로 보관합니다.

최대 1GB/15분의 브라우저 지원 MP4/MOV를 사용합니다. HEVC가 안 되면 H.264 MP4나 이미지를 사용하세요. 종·폼·기술은 한글 목록입니다. 자동 탐지는 실험적 색상 기반이며 실제 아이폰 영상 정확도는 미측정입니다. 0 IV가 두 개 이상이거나 배치가 바뀌면 누락될 수 있습니다. 보정은 같은 비율/배치에서만 재사용합니다.

- **이번 수정판의 온라인 반영은 미완료입니다.** 사이트 저장소 연결을 위한 권한 요청이 현재 환경에서 자동 거절됐습니다. 기존 사이트는 이전 버전입니다.
- `go-lens-offline.html`은 코드·스타일·DB를 포함한 로컬 실행판입니다. 브라우저로 열며 로컬 파일/Worker 지원에 따라 동작이 달라질 수 있습니다. 실제 브라우저 동작은 미검증입니다.
- 소스는 Node.js 20+에서 `node server.mjs` 후 `http://localhost:4173`에 접속합니다. `dist/index.html`만 직접 열면 모듈 경로 제한이 있습니다.
- `node --test tests/*.test.mjs` — 계산·이름·기술 제한·CP 판독·작업 연결 테스트를 실행합니다. 이번 브라우저 미리보기는 네트워크 제한으로 접속하지 못했습니다.
- `node build-standalone.mjs` — 독립 실행 HTML 재생성.

## 데이터와 개인정보

1136종/폼과 319개 PvE 기술을 포함합니다. data.json에 확인일, 원본 timestamp, 출처와 SHA-256을 기록합니다. 확인일은 실제 게임 변경일과 다릅니다. 진화 경로는 PvPoke family.evolutions를 사용하며 조건부 진화의 게임상 요건은 검증하지 않습니다.

`node update-data.mjs` 또는 다운로드한 원본 두 파일 경로를 인자로 주어 갱신합니다. 테스트와 대표 CP 경계·폼·기술·진화를 검토한 후 배포해야 합니다. 카드 원본 입력은 유지됩니다.

데이터 출처: [PvPoke](https://github.com/pvpoke/pvpoke) (능력치/타입/기술 풀/진화, MIT 고지는 NOTICE.txt) · [PokeMiners](https://github.com/PokeMiners/game_masters) (CPM/PvE 기술). 게임 데이터/명칭 권리는 각 소유자에게 있습니다.

미디어는 서버로 전송하지 않습니다. 영상은 저장하지 않고 카드 JPEG와 입력만 현재 브라우저 IndexedDB에 보관합니다. 트레이너 이름·장소가 이미지/백업에 포함될 수 있습니다. 삭제는 로컬 카드와 이미 내보낸 백업/OS 원본이 별개입니다. 저장소 정리/시크릿 모드/브라우저 이동으로 기록이 사라질 수 있습니다.

게임 로그인·인증 토큰·게임 API·클라이언트/백엔드 접근·자동 플레이·위치 위조를 사용하지 않습니다. 최신 약관 준수나 운영자 승인을 보증하는 뜻은 아닙니다.

웹은 다른 앱 화면의 지속적 실시간 접근을 가정하지 않습니다. 분석 중 탭을 열어 둡니다. 네이티브 확장은 SwiftUI + PhotosPicker + AVAssetReader + Vision OCR + SwiftData로 설계할 수 있습니다. 실시간은 사용자가 시작하는 ReplayKit Broadcast Upload Extension의 메모리·시스템 표시·심사 요건을 별도 검증해야 합니다. 네이티브 iOS 앱은 포함되지 않습니다.
