# GO Lens · 개인 포켓몬 분석 MVP

아이폰 화면 녹화/스크린샷을 사용자가 직접 선택하는 개인용 웹앱입니다. 미디어는 서버로 전송하지 않고 브라우저 Canvas에서 처리합니다. 카드 이미지는 IndexedDB에 저장하며 원본 영상은 저장하지 않습니다. 앱 소스와 공개 능력치 데이터만 호스팅합니다.

## 사용 방법

1. 사이트를 열고 `예제 카드 보기`로 계산을 확인합니다.
2. 아이폰에서 포켓몬 GO 조사 막대가 보이게 1–2초씩 유지하며 화면 녹화 후 사진 앱에 저장합니다.
3. 녹화를 선택합니다. 브라우저가 지원하는 MP4/MOV, 최대 1GB/15분입니다. 분석 중 화면을 열어 둡니다. 여러 영상도 순서대로 처리합니다.
4. 탐지된 카드를 선택합니다. 처음에는 `막대 좌표 보정`으로 전체 막대 시작/끝과 세 줄의 중앙 좌표를 설정합니다. 자동 판독 IV는 반드시 확인합니다. 보정은 같은 배치/화면 비율에서만 재사용합니다.
5. 종/폼, IV, 현재 레벨, 실제 기술과 그림자 여부를 확인하고 저장합니다. 메가는 종/폼에서 선택합니다. 레벨/기술을 모르면 PvP와 IV만 먼저 계산할 수 있습니다.
6. 누락된 화면은 영상 미리보기에서 원하는 시점으로 이동해 직접 저장합니다. 이미지 파일도 개별 카드로 추가할 수 있습니다.
7. 중요한 기록은 JSON 백업으로 내보냅니다. 백업에 스크린샷이 포함되므로 장소/트레이너 이름을 확인하고 보관합니다. iOS 저장소 정리, 시크릿 모드, 다른 브라우저로 기록이 이동하지 않습니다.

종 이름은 현재 영문 검색입니다(예: 마릴리 = Azumarill). 이름/기술 OCR은 구현하지 않았으며 보유 기술·레벨·종을 자동으로 알아냈다고 표시하지 않습니다.

## 로컬 실행

Node.js 20 이상에서 이 폴더를 열어 `node server.mjs`, 브라우저에서 `http://localhost:4173`에 접속합니다. 의존성 설치는 필요 없습니다. `index.html` 파일을 직접 여는 방식은 모듈/Worker 제한으로 지원하지 않습니다. 로컬 주소는 같은 PC 전용이며 아이폰에서는 배포된 HTTPS 사이트를 사용합니다.

`node --test tests/engine.test.mjs`로 계산·상성·합성 화면 판독 검증을 실행합니다. 실제 아이폰/Safari/녹화 영상의 호환성과 탐지 정밀도는 별도 검증이 필요합니다.

## 계산 정의

- IV% = `(공격 IV + 방어 IV + HP IV) / 45 × 100`.
- 실제 공격/방어 = `(기본 능력치 + IV) × CPM`, HP = `max(10, floor((기본 HP + IV) × CPM))`.
- CP = `max(10, floor((기본 공격 + 공격 IV) × sqrt(기본 방어 + 방어 IV) × sqrt(기본 HP + HP IV) × CPM² / 10))`.
- 반 레벨 CPM은 인접 정수 레벨 CPM 제곱의 평균의 제곱근입니다. 원본 CPM의 정밀도에 따라 극히 근접한 CP 경계에서 차이가 있을 수 있습니다.
- PvP: 동일 종/폼에서 IV 0–15의 4,096개 조합을 모두 비교합니다. 각 조합에 대해 선택한 최대 레벨까지 0.5 단위로 CP 상한 이내 최적 레벨을 찾습니다. 스탯곱은 실제 공격 × 실제 방어 × 정수 HP입니다. 최상위 대비 스탯곱%와 내림차순 경쟁 순위(동점 동일 순위)를 표시합니다. IV 백분위와 스탯곱%는 다릅니다. 상한 미달 조합은 최고 레벨을 사용하며 레벨 1도 상한을 넘으면 부적격입니다. 종간 PvP 메타 순위나 승률이 아닙니다. 메가의 PvP 순위는 제공하지 않습니다. 그림자의 공격/피해 변화는 이 스탯곱 순위에 적용하지 않습니다.
- 현재 레벨은 레이드/현재 CP 계산에만 사용하고 PvP는 잠재 육성 기준입니다. 레벨 51은 실제 베스트 파트너 보너스가 활성화된 경우에만 사용합니다.

## 레이드 MVP의 정확한 범위

보스 방어력/타입을 입력하는 **간이 사이클 DPS 비교**입니다. 보편적인 실전 S티어라고 해석하면 안 됩니다.

각 기술 피해 = `floor(0.5 × 위력 × 실제 공격 / 보스 방어 × STAB × 상성 × 그림자 공격 보정) + 1`.

스페셜 1회 충전에 필요한 노말 횟수 `ceil(소모 에너지 / 노말 획득 에너지)`를 사용하여 사이클 피해 / 사이클 시간을 계산합니다. 피격 에너지, 에너지 이월, 사망, 회피, 방어, 보스 기술, TDO, 날씨, 프렌드, 파티 파워, 메가 아군 보너스, 특수 전용 효과는 미반영입니다. 그림자 공격 1.2, STAB 1.2, GO 타입 상성, 메가 기본 능력치, 현재 레벨과 IV를 적용합니다. 그림자+메가 동시 적용은 막습니다.

동일 보스 조건에서 데이터베이스 전체 종/폼, 레벨 40, 15/15/15, 일반/그림자/메가, 기술 조합 중 최대 DPS를 100%로 두고 S≥95 / A≥85 / B≥70 / C≥55 / D<55로 표시합니다. **그림자 출시 가능 여부·엘리트/한정 기술 획득 가능성·현재 레이드 참가 제한을 검증한 티어가 아닙니다.** 화풀이/은혜갚기는 비교 기준 최적 기술에서 제외합니다. 실제 보유 기술은 수동 입력하며 기술 보유 가능 상태를 사용자가 확인합니다. 이 제한 때문에 실전 레이드 선택에는 외부 시뮬레이터 검증이 필요합니다.

## 데이터와 업데이트

1136종/폼과 313개 PvE 기술을 포함한 공개 스냅샷(최초 생성 기준)을 번들로 제공합니다. 서버가 자동으로 갱신하지 않습니다. 앱 하단에 확인일을 표시하며 실제 게임 반영일/원본 갱신일과 동일하다는 뜻은 아닙니다. 출처/원본 timestamp/각 원본 SHA-256은 `dist/data.json`에 보관합니다. PvP 기술 수치를 레이드 기술 수치로 사용하지 않습니다.

`node update-data.mjs`는 다음 공개 원본을 내려받아 스키마와 기본 데이터량을 검증하고 새 스냅샷을 만듭니다. 다시 `node --test tests/engine.test.mjs` 후 검토·재배포하세요. 원본 JSON 두 개의 로컬 경로를 인자로 줄 수도 있습니다. 업데이트는 기존 사용자 카드와 IV를 변경하지 않습니다. 저장 결과 대신 원본 입력을 보관하므로 카드를 열면 현재 번들 DB로 다시 계산합니다.

- [PokeMiners Game Master](https://github.com/PokeMiners/game_masters) — 정수 레벨 CPM과 PvE 기술 수치.
- [PvPoke 소스](https://github.com/pvpoke/pvpoke) — 종/폼 기본 능력치, 타입, 기술 풀. PvPoke MIT 라이선스를 아래 NOTICE에 기재합니다. 원본 게임 데이터/명칭의 권리는 각 소유자에게 있습니다.

업데이트 후에는 대표 CP 경계, 폼별 능력치, 신규 기술 ID, 실제 출시 여부를 검토해야 합니다. 현재 기술별 한글명/해금 조건/폼별 예외는 완전하지 않습니다.

## 자동 인식과 다음 단계 설계

현재는 영상 0.5/1/2초 샘플 → 하단 영역 색상 막대 3줄 후보 탐지 → 화면 시그니처로 최근 30개 중 중복 제거 → JPEG 카드 저장입니다. 좌표 보정이 없는 후보는 IV를 비워 두고 수동 확인을 요청합니다. 보정이 있으면 색상 채움 길이를 15등분합니다. 전환 애니메이션/색상/레이아웃/빈 막대에 따라 오탐·누락이 발생할 수 있습니다. 0 IV가 두 개 이상인 화면은 자동 후보를 놓칠 수 있으므로 수동 저장을 사용하세요. 중복 제거는 같은 IV만으로 판단하지 않지만 비슷한 화면은 잘못 합쳐질 수 있습니다. 실제 영상 표본을 이용한 정밀도/재현율 측정은 아직 하지 않았습니다.

다음 단계는 실제 사용자 녹화에서 화면 배치 프로필을 만들고 연속 안정 프레임 검증, 막대 구간/확신도 표시, 로컬 OCR(한국어·영어 종/CP/HP) 및 폼 후보 확인, 인접 기술 화면과 시간 기반 연결을 추가하는 것입니다. 어떤 값을 어떤 프레임에서 읽었는지 필드별 출처/확신도를 보관하며 불명확한 값은 미확인으로 남깁니다. 실제 레이드 티어는 보스/보스 기술/날씨/프렌드 등을 명시한 검증된 시뮬레이션 데이터셋을 버전으로 고정해 통합해야 합니다.

## iOS 네이티브 확장 설계

웹 MVP는 운영체제별 실시간 화면 공유 지원 여부에 의존하지 않습니다. 파일 선택과 브라우저 디코딩만 사용합니다. 브라우저/OS 버전별 화면 캡처 API 지원이 바뀌더라도 웹페이지가 다른 앱 화면을 임의로 계속 읽을 수 있다고 가정하지 않습니다. 백그라운드 실행 중단/화면 잠금으로 처리 작업이 멈출 수 있습니다.

네이티브 버전은 SwiftUI + PhotosPicker/PHPicker(사용자가 고른 자산만) + AVAssetReader(프레임 순차 디코딩) + Vision OCR + 로컬 SwiftData/파일 저장을 사용합니다. 실시간이 정말 필요하면 사용자가 명시적으로 시작하는 ReplayKit Broadcast Upload Extension을 별도 검토해야 합니다. 일반 앱의 화면 녹화 기능만으로 다른 앱 화면을 몰래 읽을 수 없습니다. 확장 프로세스의 메모리 제한·성능·시스템 표시·심사 요건을 검증하고 App Group에 필요한 결과만 공유합니다. 현재 배포물에 네이티브 앱은 포함되지 않습니다.

## 개인정보 및 이용 정책

게임 계정 로그인/인증 토큰/게임 클라이언트·백엔드 접근/자동 플레이/위치 위조를 구현하지 않았습니다. 사용자가 직접 저장한 미디어만 읽습니다. 분석 영상은 네트워크 전송하지 않으며 스크린샷과 입력은 현재 브라우저에 저장합니다. 삭제 버튼은 로컬 카드/보정 좌표를 삭제하고, 이미 내보낸 백업과 OS 원본 녹화는 별도로 삭제해야 합니다. 호스팅 제공자의 접속 인증/일반 접속 로그와 앱 분석 데이터는 별개입니다. 비공개 사이트 접근 정책을 유지하세요.

이 설계는 비인가 게임 접근을 피하지만 서비스 운영자의 승인이나 약관 준수 보증은 아닙니다. 실제 사용/배포 전에 최신 운영 정책을 확인하세요. [공식 비인가 접근 관련 안내](https://niantic.helpshift.com/hc/en/6-pokemon-go/faq/525-violating-the-terms-of-service/) · [Apple ReplayKit](https://developer.apple.com/documentation/replaykit) · [MDN 화면 캡처 API](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getDisplayMedia).

## 이번 검증 결과

계산/상성/합성 막대 판독 테스트 8개 통과. 로컬 브라우저에서 예제 카드 생성·선택, 세 리그 결과, 기술 선택 후 레이드 계산을 확인했습니다. 실제 아이폰 Safari와 실제 녹화 파일은 미검증입니다. 비공개 배포는 성공했으나 자동 검증 브라우저의 ChatGPT 로그인 단계에서 인증 오류가 발생했습니다. 사용자는 배포 URL에서 본인 계정으로 접속해야 합니다.
